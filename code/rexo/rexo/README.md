# Разработка

## Направления вращения

Для единообразия управляющих конструкций направления движения будем
считать по часовой стрелке смотря на человека справа - т.е.
его направление движения будет вправо. Направления будем задавать одинакого
и для левой ноги и для правой.

Для бедра мы указываем угол поворота бедра относительно туловища.
Для колена мы укаываем угол поворота голени относительно бедра.

Для полуприседа:
````
0    0
|    |
|    \
|    /
-    -
````
Бедро относительно туловища смещается против часовой стрелки, значит угол будет отрицательным (-15).
Колено относительно бедра смещается по часовой стрелке, значит угол будет положительным (+30)


# Управляющий блок

Блок имеет 4 кнопки. Логика работы с ними аналогична логике
работы кнопок на мониторе.
Пусть кнопки называются 1,2,3,4 - слева направо. Тогда:

- кнопка 1 - "Выход" - возвращает назад. 
- кнопка 2 - "Ввод" - выбор пункта меню
- кнопка 3 - "Минус 1" - перемещение по меню назад или уменьшение значения
- кнопка 4 - "Плюс 1" - перемещение по меню вперед или увеличение значения

## Меню

Верхний уровень

- Настройка
  - "LEV BEDRO INIT" - корректировка начального положения левого бедра
  - "LEV KOLENO INIT" - корректировка начального положения левого колена
  - "PRAV BEDRO INIT" - корректировка начального положения правого бедра
  - "PRAV KOLENO INIT" - корректировка начального положения правого колена
  - при возврате на верхний уровень настройки сохраняются в ПЗУ
- Присед
  - U - перейти в исходное положение
  - D - перейти в положение присед
- На месте
  - L - по очереди для левой ноги - согнуть ногу, выпрямить ногу
  - R - по очереди для правой ноги - согнуть ногу, выпрямить ногу
